# BALDRIUM_QA

Repositorio de pruebas de calidad (QA) del sistema Baldrium, desarrollado para BALDRIUM GROUP S.A.S.

## Estructura
- `logica/`: pruebas de la capa de lógica (rutas, servicios y utilidades).
- `persistencia/`: pruebas de la capa de persistencia (repositorios y acceso a MySQL).

## Tecnologías
Node.js, Express, MySQL, Jest y Supertest.

## Requisitos
- Node.js (versión LTS)
- MySQL en ejecución, con la base de datos del proyecto

## Cómo ejecutar las pruebas
1. Clonar el repositorio y entrar a la rama de trabajo.
2. En cada carpeta (`logica` y `persistencia`):
   npm install
   npm test

## Flujo de trabajo
- Cada integrante crea su propia rama a partir de la rama de trabajo.
- Los cambios se integran mediante Pull Request.
